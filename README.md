# 🚀 Mohamed Shaheel - AI/ML Portfolio

A modern, responsive portfolio website built with React, Vite, and Tailwind CSS.

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shaheel-08/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Add your profile photo:
   - Place your photo at `public/profile-photo.jpg`
   - Recommended size: 500x500px

4. Add your resume PDF:
   - Place your resume at `public/resume.pdf`

5. (Optional) Add project images:
   - Place images in `public/projects/`
   - Naming: `pii-detection.jpg`, `drone-victim.jpg`, `medconnect.jpg`

## 🚀 Development

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
